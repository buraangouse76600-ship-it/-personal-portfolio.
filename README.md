# B Mahammad Gouse — Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy
Import this GitHub repository into Vercel. Framework preset: Other; Build Command: leave empty; Output Directory: `.`.

## Customize
Edit `index.html` for profile details and projects, `style.css` for appearance, and `script.js` for interactions. Skill bars use the `--level` CSS variable. Project cards are intentionally labelled as concepts until real implementations exist.

The contact section uses a `mailto:` link and does not collect form submissions.
